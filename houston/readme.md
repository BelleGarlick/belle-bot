# Houston

Houston is the management and visualization component for `belle-bot`.

## Documentation

Detailed documentation for Houston's components can be found in the `docs/` directory:

- [Overview](docs/overview.md)
- [Server](docs/server.md)
- [Frontend](docs/frontend.md)
- [Client](docs/client.md)

## Quick Start

### Running the API
```bash
./houston/scripts/api.sh
```

### Building the Frontend
```bash
./houston/scripts/build-fe.sh
```

### Generating API Client
```bash
./houston/scripts/build.sh
```
